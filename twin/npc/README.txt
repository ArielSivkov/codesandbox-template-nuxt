ממשק לצוות התחבורה
------------------
const npc = await NPC.create({...});              // או רק NPCCrowd.create({scene, assets, vendor})
npc.density()   → { pedestrians, cars, dayType, approx:true }   מכפילים יחסית ליום חול בצהריים (שבת: רכבים ×0.12)
npc.isShabbat() → true/false
npc.crowd.push({ x, y, z, heading, anim:'walk'|'idle'|'run'|..., speed, seed, look? })   בכל פריים, לפני npc.update / crowd.end
   (או ב-o.extra: () => [...] של NPC.create). בלי look → NPCCrowd.randomLook(seed). התקציב (80 קרובים) משותף.
NPCCrowd.CLIPS – שמות האנימציות.

מה מקורב (כתוב גם בקוד)
------------------------
- זמני שבת (20/40 דק'), סיווג בניינים לא מתויגים (96% מהבניינים באריחים בלי סוג), "פארקים" = שטחים פתוחים בלי בניינים/כבישים
  (אין שכבת פארקים באריחים), חוף = קו המים מהאריחים, נמל = בניין תעשייה גדול ליד הים. בתי כנסת: רק 2 מתויגים ב-OSM באזור –
  כשאין בית כנסת קרוב, יעד "התכנסות" בשטח פתוח (מסומן approx). כדאי להוסיף לצינור amenity=place_of_worship / shop / park.
- צפיפות התחבורה (density) – עקומות סבירות, לא נתוני ספירה.
