# גרעין הסגנון של אשדוד החיה · v0

הגרעין הוא מה שכל סוכן בעולם (world.esh27.com) מקבל לפני שהוא נוגע בחלקה: אילו צבעים מותרים בכל שעה, איך האור נראה לפי גובה השמש, מאילו חומרים העיר עשויה, איך מותחים קו, איך כותבים עברית, ומה אסור.
הסגנון לקוח מהיצירה "אורות דתוהו בכלים דתיקון" (23.11.2026). לקחנו רק את הסגנון, בלי שמות, בלי סכומים ובלי שום תוכן אישי.

| קובץ | מה יש בו |
|---|---|
| `style.json` | האסימונים הקריאים למכונה: פלטה לפי תפקיד ושעה, מודל אור, חומרים, קו וחריטה, טיפוגרפיה, קומפוזיציה, וכללי אמת, פרטיות, קדושה ונכסים דיגיטליים. כולל `version` ו-`schema` (JSON Schema). |
| `sky.js` | מודול ES בלי תלויות (דפדפן, Workers, Node): שמש, ירח, מופע, זריחה ושקיעה, דמדומים, וצבעי השמיים לרגע אמיתי. |
| `fonts/` | היבו ופרנק ריהל (woff2, ‏OFL) ו-`fonts.css`. |
| `test/` | `sky.test.mjs` מול ערכי PyEphem ב-`reference.json`. |
| `tools/` | `make_reference.py` (מייצר את ערכי הייחוס) ו-`shot.mjs` (מצלם את גיליון התצוגה). |
| `preview/` | `index.html` ו-`kernel-sheet.png`: יום שלם של שמי אשדוד, ארבעה רגעים, הפלטה והחומרים. |
| `plates/` | שלושה לוחות השראה של אותו אזור: לילה, זריחה וצהריים, ב-2400 פיקסלים וב-8K, עם קוד הרינדור ורשומות הבדיקה. |

## שבעת הכללים

הסדר הוא סדר הקדימות: כשיש התנגשות, כלל מוקדם גובר על כלל מאוחר.

1. **אמת לפני יופי.** סגנון לעולם לא משנה גאומטריה, גובה, מיקום או צבע שנמדדו. הוא חל רק על מה שלא נמדד: מרקם, קו וטון.
2. **מה שמשוער, מסומן.** כל קירוב נושא את המילה "משוער" (בתרשים: "סכמטי"), וכל גובה נושא ± (למשל 18 מ׳ ±3). מה שנמדד מצויר בקו חד. מה שמשוער מצויר ברצועה רכה או בקו מקווקו.
3. **קו אחד של מוקד.** בכל סצנה יש אלמנט מוקד אחד, בזהב השמור (‎#FFC86B‎ עם ליבה ‎#FFF6E0‎). כל השאר מוגבל ל-35% מבהירות המוקד, ונבדק בתמונה מוקטנת ל-1080 פיקסלים.
4. **שקט וחריטה.** כל מה שאינו המוקד מצויר כחריטה שקטה: קווי שיער, הצללה ומיקרוגרפיה. לפחות 40% מהמסגרת נשארים שדה רגוע, וכל האקראיות נובעת מזרע.
5. **שמיים אמיתיים.** השמש, הירח, הכוכבים וצבע השמיים מחושבים ב-`sky.js` לרגע ולמקום האמיתיים. לא ממציאים ירח.
6. **פרטיות.** אין אנשים, אין פנים ואין לוחיות רישוי. אין שמות של דיירים או בעלים, ואין תוכן אישי. מתמונות הרחוב נכנסים רק נתונים מצרפיים, כמו צבע וחומר.
7. **דבר קדוש לא נמכר.** אין שמות קודש ואין פסוקים באמנות. בשום מקרה הם לא יופיעו בנכס שנמכר, נטבע או משמש לפרסום. מסגרת קבלית מותרת רק כשהיא מופשטת ובכבוד.

ב-`style.json` → `digitalAssets` מפורטים כללי ווב 3, הנכסים הדיגיטליים והמטאברס:
- חלקה בעולם היא תמונה של הקרקע, לא זכות בה.
- לכל נכס מצורף מקור משוחזר: גרסה, זרע, זמן תמונת המצב ורישיונות.
- לא מתחזים לבעלים, לעירייה או לרמ״י.
- שום דבר לא נטבע, נמכר או עולה לאתר החי בלי אישור מפורש של אריאל.

## sky.js בקצרה

```js
import { sunTimes, moonPosition, moonPhases, skyColors, roleColor, shade, seededRandom, brightnessBudget } from './sky.js';

// זמני השמש ליום המקומי בישראל (ברירת מחדל: נמל אשדוד, 31.8014N 34.6435E, שעון ישראל כולל שעון קיץ)
const t = sunTimes(new Date('2026-11-24T10:00:00Z'));
t.local.sunrise;       // '06:17'
t.local.sunset;        // '16:38'
t.local.civilDusk;     // '17:04'   גם nautical*/astronomical*, solarNoon, goldenHour*, blueHour*
t.list;                // רשימה ממוינת עם תוויות בעברית

// הירח ברגע של היצירה
const m = moonPosition('2026-11-23T20:30:00Z');
m.illumination;        // 0.9895
m.alt;                 // 80.6 (מעלות, טופוצנטרי). גם az, altApparent, semidiameter, phase.he
moonPhases('2026-11-20T00:00:00Z').fullMoon;   // 2026-11-24T14:53Z, כלומר 16:53 בשעון ישראל

// צבעים לרגע אמיתי ולחלקה
const sky = skyColors('2026-11-23T20:30:00Z', { lat: 31.79, lon: 34.65 });
sky.stops;             // [{at:0, hex:'#08102A'}, …, {at:1, hex:'#16224A'}]  (0 = זנית, 1 = אופק)
sky.phase.he;          // 'לילה'
sky.ambient; sky.shadowTint; sky.sunLight; sky.sunward; sky.antisun; sky.windowLightProbability; sky.focus;
```

- **מקום אחר:** `{ lat, lon, elevation, tz }`. השדה `tz` מקבל דקות מ-UTC, פונקציה, או שם IANA (דורש Intl).
- **ללא Intl:** שעון ישראל מחושב לפי חוק 2013 ואינו דורש Intl.

**בדפדפן ובוורקר:** `import * as Sky from '/style-kernel/sky.js'`. אין צורך ב-DOM או ב-fetch.

## דוגמאות

**1. סוכן מצייר חלקה ב-22:30.**
```js
import style from './style.json' with { type: 'json' };      // או fetch בדפדפן
const sky = skyColors(date, { lat, lon });
const sea = roleColor(style.palette.roles.sea_surface, sky);  // מיזוג חלק בין לילה, שחר, יום ושקיעה
const wall = shade(style.materials.items.plaster.base, sky, { lamp: 'sodium' });   // קיר טיח ליד פנס
const rnd = seededRandom(`window:${parcelId}/w07|2026-11-24|22`);
const lit = rnd() < sky.windowLightProbability;               // אותו קלט, אותה תוצאה
```

**2. מוקד ביום.** `sky.focus.mode === 'ink'` אומר שביום הקו הוא דיו מוזהב (‎#E3A33A‎ עם שפה ‎#1A1408‎) ולא אור. המטרה ביום היא הניגודיות הגבוהה ביותר, לא הבהירות.

**3. עברית נכונה.** משתמשים ב-רו״ח, תשפ״ז ו-ד׳ עם גרשיים וגרש אמיתיים (U+05F4, U+05F3) ולא במירכאות ASCII. תאריך נכתב 24.11.2026 ושעה 06:17. כותרת שמגיעה מנתונים נעטפת ב-RLI…PDI, ומילה לטינית ב-LRI…PDI. טקסט עברי מצויר ב-SVG או ב-HTML, לא ב-`fillText`.

**4. בדיקת תקציב הבהירות.** מקטינים את התמונה ל-1080 פיקסלים ומריצים:
```js
const r = brightnessBudget({ data, width, height }, (x, y) => inFocalMask(x, y));
r.pass;   // P99 של Y מחוץ למסכה ≤ 0.35 × Y(המוקד)
```
ביום בודקים ניגודיות מול הנייר (`{ background }`) ולא בהירות. אותיות של טקסט ומפתחות צבע במקרא פטורות (`{ exempt }`), כי טקסט קריא לא נכנס ב-35% מניגודיות המוקד. צללים, קווים וכל השאר נבדקים.

## דיוק (נמדד מול PyEphem 4.2.1)

הבדיקות רצות על 68 רגעים ב-2026 בשש נקודות: אשדוד (53), ירושלים, אילת, טרומסו, סידני וקיטו.

| מה | סף | הסטייה הגרועה שנמדדה |
|---|---|---|
| שמש: גובה / אזימוט | ‎0.2°‎ | ‎0.010° / 0.044°‎ |
| ירח: גובה / אזימוט | ‎0.7°‎ | ‎0.005° / 0.011°‎ |
| חלק מואר של הירח | 1.5% | 0.2% |
| זריחה, שקיעה, חצות היום ושלושת הדמדומים (48 ימים) | 2 דק׳ | 0.42 דק׳ |
| זריחת הירח, שקיעתו ומעברו | 3 דק׳ | 0.03 דק׳ |
| מולד, רבעים וירח מלא | 5 דק׳ | 1.1 דק׳ |

ההגדרות:
- זריחה ושקיעה נקבעות כשמרכז השמש ב-‎−0.833°‎ (מוסכמת NOAA), בלי תיקון לגובה הצופה.
- זהו דיוק נמוך בכוונה: מספיק לאמנות, לאור ולכיוון הצל. הוא לא מתאים לניווט ולא לפסק הלכה.
- הסטייה הגדולה ביותר בזמני השמש (0.42 דק׳) נמדדה בשקיעה בטרומסו בינואר, שם השמש נעה כמעט במקביל לאופק. באשדוד הסטייה הגרועה היא 0.07 דק׳ (4 שניות).
- הסטייה הגדולה באזימוט השמש (‎0.044°‎) נמדדה כשהשמש בגובה ‎80°‎, קרוב לזנית, שם האזימוט רגיש מאוד.
- בתוך המנוע של העולם התאום, מקור האמת לשמיים הוא `twin/sky` (ESH27Sky, דיוק גבוה, תאריך עברי וזמני היום). `sky.js` הוא הגרסה הקלה והעצמאית לסוכנים ולאמנות.

## לוחות ההשראה

שלושה לוחות של אותו אזור, "אשדוד · בין הים למגדלי הדקל" (‏`plates/AREA.json`, מלבן של 640×660 מ׳). המבט בכולם מאזימוט 120° אל הים.
- **לילה** (`night.png`), ‏23.11.2026 בשעה 22:30: הירח בגובה ‎80.6°‎, ולכן הצללים קצרים (‎0.165‎ × הגובה) ונופלים לכיוון ‎348°‎. המוקד הוא קו המתאר של מגדל הדקל המערבי.
- **זריחה** (`sunrise.png`), ‏24.11.2026 בשעה 06:17:28: השמש באזימוט ‎113.8°‎. רק מה שגבוה מ-36–48 מ׳ מעל הים כבר מואר. המוקד הוא קו האור הראשון.
- **צהריים** (`noon.png`), ‏24.11.2026 בשעה 11:28:06: השמש בגובה ‎37.6°‎, בדיוק בדרום. הצללים נופלים לצפון האמיתי באורך 1.3 × הגובה. המוקד הוא קו הצהריים.

כל הגבהים, חוץ משני מגדלי הדקל (‏100 מ׳ ±8, משוער מתמונות שטח), נגזרים מכלל אצבע (‏R, ‏±6–20 מ׳). קו החוף בדגימה סינתטי, ולכן הוא מסומן "סכמטי". הלוחות לא נותנים שום זכות בקרקע האמיתית.

## מה עוד לא בגרסה 0

- עננים, אובך ואבק מנתוני מזג אוויר אמיתיים. כשהם קיימים הם גוברים על צבעי השמיים הנקיים.
- הדפוס השונה של אורות בשבת ובחג.
- קווי מתאר אמיתיים בגיליון התצוגה (`preview/`): שם כל צללית עדיין מסומנת "סכמטי". הלוחות (`plates/`) כבר בנויים מקווי המתאר של OSM בעולם התאום.
- החומרים ועקומת החלונות הם השראה, לא מדידה. כשיהיו מדידות מתמונות מכוילות, הן יחליפו את הערכים ומקורן יירשם.
